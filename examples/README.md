# Reproducible Vision input assets

These 11 example images are input stimuli for the Qwen3.8-27B Text/Vision showcase, **not images generated by the model**. The six annotated scenario images and two numeric OCR cards are natively 1280×960, and three other inspection photos are 1024×768. Some scenario inputs are illustrations rather than photorealistic or 3D renders.

The authoritative filenames, native dimensions, byte sizes and SHA-256 digests are recorded in [assets_manifest.json](assets_manifest.json). Each scenario's prompt, label, and expected textual checks live in [vision_showcase_cases.json](vision_showcase_cases.json).

The notebook fetches a pinned Git commit and verifies the manifest. High-resolution replacement assets constitute a new acceptance dataset. Previous benchmark or OCR scores cannot be transferred to the replacement images; fresh TPU inference and a new executed notebook are required.

The synthetic demonstration images and diagrams may be displayed for showcase input review. Do not describe them as real photographs or Qwen-generated outputs.
