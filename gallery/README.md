# Static Inference Results Gallery

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](README.vi.md)

A **CPU-only** static web page for displaying Qwen3.8-27B Text + Vision outputs generated by a notebook execution. The page presents English and (when separately generated) Vietnamese answers as **independent inferences**, grouped into five tasks, alongside 16 original image inputs with SHA256, all 19 case IDs, EOS, timing, search and downloadable evidence JSON. It is not an inference server.

## Kaggle notebook switches

The [notebook](../notebooks/kaggle-tpu-v5e8-production-showcase.ipynb) finishes and saves all **19 original English cases first**. The following environment variables are read later:

- **QWEN38_ENABLE_VI=0**: no additional inference; Vietnamese results are explicitly marked *not generated*. Each numeric OCR card reuses its own recorded digit result in the Vietnamese view; the two OCR cases remain separate.
- **QWEN38_ENABLE_VI=1** (default): request **17 independent Vietnamese generations** (3 Text, 6 Rich Vision, 8 Photography) with the **same loaded MaxEngine**, saving raw text, token IDs, EOS, per-case timing and errors separately in cases/full19-vi.json. The original English evidence is never overwritten. The Gallery renderer uses the actual EN/VI JSON generated during the notebook execution. Case-level evidence remains bound to its source hashes.
- **QWEN38_RENDER_HTML=1** (default): after inference, render gallery/index.html, gallery/evidence.json, gallery/assets/ and inference-gallery.zip with **CPU only**. Set to 0 to skip HTML export.

Configure the switches before Run All. The first code cell documents the defaults and can be edited if needed. The gallery never invents Vietnamese answers or reruns OCR.

## Open Gallery via Cloudflare Tunnel inside Kaggle

**Cell 17** launches Cloudflare Quick Tunnel **only when Kaggle reports an Interactive editor session** (`KAGGLE_KERNEL_RUN_TYPE=Interactive`) and `QWEN38_TUNNEL_ENABLED=1`. Turn **Internet = On** to use it in the interactive editor. The temporary URL is printed in the cell output and is usable while that cell is running.

**API/CLI runs and Save & Run All on the Kaggle UI are Batch sessions**. Cell 17 skips Cloudflare entirely in Batch or unknown environments: **no extra 900-second hold and no network download**. The CPU-built `inference-gallery.zip`, evidence JSON and recorded answers remain available as outputs. A local CPU host can serve this ZIP later without restarting TPU.

For interactive sharing only, `QWEN38_TUNNEL_HOLD_SECONDS=900` is the default (allowed range 60–3600 seconds) and continues to consume TPU-session quota while the link is active. The pinned cloudflared 2026.10.5 binary is SHA256-verified. Only the Gallery folder is served; the URL expires when the cell/session ends and is never saved as a durable artifact. Network restrictions may block sharing. Cell 17 changes only the HTML heading from *Internal review* to *Inference showcase* and refreshes the ZIP; raw EN/VI JSON and evidence SHA256 stay unchanged.

## Rebuild from a genuine run on CPU

No extra packages, network connection, GPU or TPU are needed:

    python3 gallery/render.py \
      --en /path/to/cases/full19-final.json \
      --vi /path/to/cases/full19-vi.json \
      --images examples/images \
      --manifest examples/assets_manifest.json \
      --output /path/to/new-gallery

Omit --vi if the optional phase did not run. The builder requires a completed 19-case original JSON, checks group counts, input-image hashes and the 16-image manifest, and refuses to overwrite an existing populated output directory. If SHA256 does not match, provide the **exact image files from that TPU run**, not approximations or regenerated images.

Download and extract `inference-gallery.zip` on a CPU computer. Its `gallery/` directory contains `index.html`, `evidence.json` and `assets/`; viewing it does not require a Git clone.

Serve either that extracted directory or a new Gallery built by the renderer:

    python3 -m http.server 8080 --bind 127.0.0.1 --directory /path/to/gallery

Open http://127.0.0.1:8080. This is sufficient for local viewing. For an optional public Quick Tunnel, first download/clone this repository on the **Linux CPU host**: the Gallery ZIP does **not** contain `gallery/install_cloudflared.sh`. From the repository root, install the binary (no sudo):

    bash gallery/install_cloudflared.sh --check
    bash gallery/install_cloudflared.sh
    "$HOME/.local/bin/cloudflared" --version

The script downloads the pinned Cloudflare release 2026.10.5 for Linux x86_64 or arm64, checks the officially published SHA256, applies chmod 755, and refuses to overwrite an unverified existing file. Set QWEN38_CLOUDFLARED_BIN_DIR to choose a different installation directory. For macOS/Windows see the [official Cloudflare installation guide](https://developers.cloudflare.com/tunnel/downloads/).

For a temporary public address, use another terminal on the CPU host:

    "$HOME/.local/bin/cloudflared" tunnel --url http://127.0.0.1:8080

If you changed QWEN38_CLOUDFLARED_BIN_DIR, replace the binary path accordingly. Keep the HTTP server running while the tunnel is active.

Stop the TPU session after downloading the ZIP to avoid unnecessary quota consumption. Cloudflare Quick Tunnel expires when cloudflared stops. Do not expose the Kaggle notebook or restricted weights.

## Integrity and safety

The exported site uses local images, inline script-safe JSON and no external JS, CSS or network calls. It preserves output errors and incomplete statuses. **EOS is not an accuracy guarantee**; generated answers need human assessment. Review evidence.json before publishing because it includes model outputs and run metadata. Unit and browser tests use **synthetic fixtures only**, which must never be represented as actual TPU inference.

## Resume without losing recorded results

The optional VI cell verifies the original Full19 SHA256 and resumes unrecorded VI cases **within the same running Kaggle session**. Already completed responses are never overwritten. Failed/incomplete rows are retained; to retry only these rows set QWEN38_RETRY_VI_INCOMPLETE=1 and rerun the VI cell. Failed attempts remain in retry_history. The inference prompts are checked against fixed prefill/decode budgets before execution. Running the entire notebook again creates a new RUN_ROOT; it does not resume a previous session.

After completing additional VI cases, rerun only the Gallery cell: it refreshes an existing verified Gallery for the same English run and replaces inference-gallery.zip with the updated export. Download or copy the previous ZIP first if you need to retain it. The standalone renderer also supports --refresh to replace only a verified Gallery belonging to that same English source. The renderer requires SHA256-bound VI results and retains incomplete/error status instead of inventing replies. Gallery-only changes can be validated independently on CPU using complete SHA256-pinned EN/VI records. The gallery renders only supplied, source-verified records.

## Task-based inference Gallery

The CPU-only renderer presents all 19 task cases in five functional groups: charts/diagrams (4), image data extraction (4), scene understanding (6), numeric OCR (2), and text questions (3). Select an example to see the source image and independent EN/VI model outputs. The task-based interface works without any human evaluation file.

To add the **optional, preliminary** pairwise semantic-review overlay:

```bash
python3 gallery/render.py \
  --en /path/to/run/cases/full19-final.json \
  --vi /path/to/run/cases/full19-vi.json \
  --images /path/to/verified/images \
  --manifest examples/assets_manifest.json \
  --review /path/to/semantic-review.v1.json \
  --output /path/to/new-gallery
```

Without `--review`, Gallery never invents translations, reference answers, or semantic ratings. The notebook invokes the renderer from the verified source bundle and checks for `RUN_ROOT/semantic-review.v1.json` only when available. Inference JSON and source images remain unchanged.

The optional review is accepted only for a completed 17-case VI run and must match the exact EN and VI SHA256 digests, the generated evidence JSON SHA256, all 17 non-OCR case IDs, and supported review fields. It is a **preliminary manual comparison, not a certified accuracy or translation benchmark**. Valid overlay exports remain separate: `semantic-review.v1.json`, `manual-comparison.en.md`, and `manual-comparison.vi.md`.


## Strict source binding and safe refresh

Each newly generated Gallery now includes `source-full19.sha256` containing the SHA256 of the original English JSON. A refresh checks this exact digest, and also compares source metadata and each recorded English case. If the sidecar is absent, the renderer checks detailed case and run metadata instead; it does not claim byte-for-byte source provenance. A supplied but missing `--vi` file is an error, never silently interpreted as “VI not generated.”

Image hashes, review provenance and the generated evidence SHA256 are checked before creating the output directory. An invalid optional review therefore does not leave a partially populated new Gallery. The Gallery renderer can be validated on CPU with explicitly labeled synthetic fixtures. Actual TPU inference and output validation belong to the final Kaggle notebook run.


## One Gallery implementation, two execution paths

The canonical, CPU-only renderer is gallery/render.py. The notebook calls the
verified offline source module; source parity is checked with:

    python3 support/sync_gallery_notebook.py --write
    python3 support/sync_gallery_notebook.py --check

Gallery changes can be accepted on CPU using verified EN/VI JSON plus the
16 original source images; there is no GPU/TPU inference cost. When a user runs
the notebook end to end, it generates the same HTML structure from that run.

For selected findings, pass --review path/to/semantic-review.v1.json.
Notes are validated against EN, VI and Gallery evidence SHA256 hashes. Only
cases with human-confirmed findings have review labels; the others remain
Not reviewed. All original model responses remain unmodified.
